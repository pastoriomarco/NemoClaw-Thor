Nodes you can add (id: summary), by category:
- assistant:
  - assistant.build_scene_selection: Builds the scene-selection context, which holds the request text and the candidate scene objects, and writes it to output_key.
  - assistant.query_model: Sends one bounded request to a model endpoint and stores the response under output_key after its schema check passes.
  - assistant.validate_scene_selection: Checks a model's selection response against the scene-selection context and writes the accepted result to output_key.
- control_flow:
  - fallback: Runs its children in order and succeeds at the first child that succeeds; it fails only when every child fails.
  - inverter: Inverts the result of its single child: a child success becomes a failure and a child failure becomes a success.
  - parallel: Ticks all of its children on every tick and decides its result by success_policy.
  - repeat: Runs its single child again after each success and succeeds after num_cycles successful runs; a child failure fails the node at once.
  - retry: Runs its single child and runs it again after each failure, so the node succeeds on the first child success.
  - sequence: Runs its children in order and succeeds when all of them succeed; it fails at the first child that fails.
  - timer: Succeeds after duration_s seconds of Program time.
- geometry:
  - geometry.check_pose_bounds: Checks whether a stored pose lies inside an axis-aligned position box.
  - geometry.check_pose_distance: Compares two stored poses against translation and rotation thresholds.
  - geometry.offset_pose: Applies a translation and a roll-pitch-yaw rotation to a stored pose and writes the result to a blackboard key.
- gripper:
  - gripper.check_status: Reads the gripper target's current command state once and compares it with expected_state.
  - gripper.command_position: Commands a gripper to a numeric position or to its open or closed preset and waits for the command to complete.
  - gripper.wait_for_status: Waits until the captured gripper command reaches expected_state.
- io:
  - io.check_input: Reads one boolean input signal once and compares it with expected_value.
  - io.clear_outside_change: Clears the changed-outside flag of one output signal.
  - io.get_input: Reads one boolean input signal once into a blackboard key.
  - io.set_output: Sets one boolean output signal of a component once.
  - io.wait_for_input: Waits until one boolean input signal equals expected_value.
- logic:
  - logic.check_condition: Succeeds when its boolean condition is true and fails when it is false.
  - logic.check_value: Compares one declared blackboard key with a value and succeeds when the comparison holds, failing otherwise.
  - logic.set_value: Writes one declared blackboard key and succeeds once the value is stored.
  - logic.wait_for_value: Waits until a declared blackboard key compares true with the value, then succeeds.
  - rules.set_active: Activates or deactivates one global interrupt rule of the Deployment and succeeds at once.
- model:
  - model.get_frame_pose: Resolves one component frame's pose from the target's current observed state, in the cell frame.
- motion:
  - motion.follow_cartesian_path: Moves the TCP through an ordered list of waypoints as one Cartesian path.
  - motion.move_to_joint_target: Moves the robot to a set of joint targets.
  - motion.move_to_pose: Moves the robot's TCP to a pose.
  - motion.move_until_signal: Moves the robot to a stored pose and stops it early when the interrupt condition trips.
  - motion.probe_search: Moves the robot toward a stored pose to find contact and stops it when the interrupt condition trips.
  - motion.set_tcp: Sets the robot's Active TCP, the TCP that later Current moves use.
  - planning.plan_pick_sequence: Plans and validates a pick sequence for one scene object, made of approach, descend, gripper close and retreat legs.
