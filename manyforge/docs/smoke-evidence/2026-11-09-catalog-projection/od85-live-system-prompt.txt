Nodes you can add (id: summary), by category:
- control_flow:
  - fallback: Runs its children in order and succeeds at the first child that succeeds; it fails only when every child fails.
  - inverter: Inverts the result of its single child: a child success becomes a failure and a child failure becomes a success.
  - parallel (success_policy?): Ticks all of its children on every tick and decides its result by success_policy.
  - repeat (num_cycles?): Runs its single child again after each success and succeeds after num_cycles successful runs; a child failure fails the node at once.
  - retry (num_attempts?): Runs its single child and runs it again after each failure, so the node succeeds on the first child success.
  - sequence: Runs its children in order and succeeds when all of them succeed; it fails at the first child that fails.
  - timer (duration_s, duration_while_held?): Succeeds after duration_s seconds of Program time.
- geometry:
  - geometry.check_pose_bounds (pose, frame_ref, min_position_m, max_position_m, inclusive?): Checks whether a stored pose lies inside an axis-aligned position box.
  - geometry.check_pose_distance (pose_key_a, pose_key_b, translation_threshold_m, rotation_threshold_rad): Compares two stored poses against translation and rotation thresholds.
  - geometry.offset_pose (pose, offset, output_key, offset_frame?): Applies a translation and a roll-pitch-yaw rotation to a stored pose and writes the result to a blackboard key.
- gripper:
  - gripper.check_status (target, expected_state): Reads the gripper target's current command state once and compares it with expected_state.
  - gripper.command_position (target, position, max_effort?, command_duration_s?, wait_for_duration?, required_inputs?, …): Commands a gripper to a numeric position or to its open or closed preset and waits for the command to complete.
  - gripper.wait_for_status (target, expected_state, timeout_s, timeout_while_held?): Waits until the captured gripper command reaches expected_state.
- io:
  - io.check_input (signal, expected_value, mock_simulation?): Reads one boolean input signal once and compares it with expected_value.
  - io.clear_outside_change (signal): Clears the changed-outside flag of one output signal.
  - io.get_input (signal, output_key, mock_simulation?): Reads one boolean input signal once into a blackboard key.
  - io.set_output (signal, value): Sets one boolean output signal of a component once.
  - io.wait_for_input (signal, expected_value, edge?, timeout_s?, mock_simulation?): Waits until one boolean input signal equals expected_value.
- logic:
  - logic.check_condition (condition): Succeeds when its boolean condition is true and fails when it is false.
  - logic.check_value (key, value, operator?, tolerance?): Compares one declared blackboard key with a value and succeeds when the comparison holds, failing otherwise.
  - logic.set_value (key, value): Writes one declared blackboard key and succeeds once the value is stored.
  - logic.wait_for_value (key, value, operator?, tolerance?, timeout_s?, timeout_while_held?): Waits until a declared blackboard key compares true with the value, then succeeds.
  - rules.set_active (rule_id, active): Activates or deactivates one global interrupt rule of the Deployment and succeeds at once.
- model:

- motion:

  - motion.move_to_pose (target, base_frame, goal, tcp_endpoint?, target_mode?, target_reference?, …): Moves the robot's TCP to a pose.
  - motion.move_until_signal (target, base_frame, goal, stop_mode, interrupt_condition, tcp_endpoint?, …): Moves the robot to a stored pose and stops it early when the interrupt condition trips.
