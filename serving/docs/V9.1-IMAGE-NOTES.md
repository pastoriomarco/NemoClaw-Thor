## Why this image exists

v9 (vLLM 0.22.0) cannot load `nvidia/Qwen3.6-35B-A3B-NVFP4` weights — crashes at 67% with:
```
ValueError: There is no module or parameter named 'lm_head.input_scale'
in Qwen3_5MoeForCausalLM. The available parameters belonging to lm_head
(ParallelLMHead) are: {'lm_head.weight'}
```
PR #42124 (merged 5 days after v0.22.0 was tagged) adds `quant_config` to `ParallelLMHead` for Qwen3.5/Qwen3.6 and Nemotron-H model classes. NVIDIA's model card explicitly recommends `vllm/vllm-openai:nightly` for this reason.

This image picks up #42124 plus 179 other commits on `main` since v0.22.0 was cut.

## Known build gotcha
The `wheels/` directory accumulates vLLM wheels from prior builds. The runner stage's `uv pip install` fails with "Requirements contain conflicting URLs for package `vllm`" if more than one `vllm-*.whl` is present. Delete the old wheel before the runner stage:
```sh
rm wheels/vllm-0.22.1.dev0+g0b3ba88f1*.whl   # remove the v9 wheel
```
